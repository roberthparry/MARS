Start Here

          
Choose a mode, enter the problem or use its date and location controls, then press Evaluate. Each mode keeps its own worksheet and working precision. Help fills the workspace with guidance for the selected mode; press Return to worksheet to return to your editor and cards.

          
    
            
  • Expression: type a formula, then set any variable values needed for numeric evaluation. Symbolic operations such as Dx(...) can run with their differentiation variables left blank.
    • 
            
  • Equation: type an equation; use the binding roles to distinguish unknown variables from fixed constants and supply numerical starting guesses where needed.
    • 
            
  • Differential Equation: type an ODE followed by optional semicolon-separated initial or boundary conditions.
    • 
            
  • Matrix: type the complete matrix expression, then press Evaluate.
    • 
            
  • Integrator: type the integrand, then add one row per variable you want to integrate over.
    • 
            
  • Datetime: choose dates, a year, and a location to calculate calendar and solar facts.
    • 
            
  • Almanac: choose a GMT moment and observer location to inspect navigational bodies, visibility, and local eclipse/transit events.
    • 
          

        

        

          
Your Worksheet And Cards

          
    
            
  • Back and Forward navigate the current mode's worksheet history. Switching modes does not discard your other worksheets; edits and controls are saved between sessions.
    • 
            
  • Copy on the editor copies its input; each result card has its own copy action. Mathematical display can differ from reusable source notation.
    • 
            
  • Use a card's zoom controls where available, or Expand for a long result. Expanding a shortened mathematical result reveals its full source; copying does not truncate it.
    • 
            
  • Hold Shift and use the mouse wheel over a 2-D or 3-D plot to zoom in or out, including when expanded. Ctrl-wheel tilts 3-D plots and Alt-wheel turns them; otherwise, without Shift, the wheel keeps its normal scrolling behaviour. The percentage button resets zoom; scrolling outside the plot image works normally.
    • 
            
  • Use as input, when shown, returns a reusable result to the editor. It is not the same as copying the rendered TeX.
    • 
            
  • Read the status and any error diagnostic before treating a result as complete. A failed calculation or timeout is not a numerical answer.
    • 
          

        

        

          
Precision And Numerical Notation

          
    
            
  • More precision and Less precision change the working arithmetic precision for subsequent calculations, not just the number of characters on screen. Evaluate again to obtain a new result.
    • 
            
  • The status shows decimal digits and binary bits. Higher precision may take longer; it does not make an unsuccessful numerical search exhaustive or remove a domain restriction.
    • 
            
  • Small results use ordinary decimals down to 0.0001; smaller magnitudes use notation such as 2.5×10⁻⁵, with no space before ×10. Real and imaginary parts follow the same rule.
    • 
            
  • = denotes an exact result and ≈ a numerical approximation where those relations are shown. Genuine complex values retain their imaginary part.
    • 
            
  • Input accepts scientific notation such as 2.5e-5. Function copying and execution preserve executable source even when the card displays superscript exponents.
    • 
          

        

        

          
What The Result Cards Mean

          
    
            
  • Rendered TeX shows the simplified symbolic answer without its binding list.
    • 
            
  • Expression shows that same answer with its variable and constant bindings. An unset binding is shown as ?.
    • 
            
  • Function expresses the same calculation as reusable MARS source, followed by binding declarations and initialisations.
    • 
            
  • Value is separate: it appears when a numerical answer exists. Simplification can make a value independent of an unset symbol; for example, sin(x)^2 + cos(x)^2 has value 1.
    • 
            
  • Entering binding values normally changes Value, not the symbolic algebra in the other cards. For integral transforms, supplied constant parameters are specialised consistently and any remaining domain conditions are retained.
    • 
          

        

        

          
Plotting A Function

          
    
            
  • Evaluate a formula and press a variable's plot button. In the plot card, choose variables with radio buttons and keep each From/To range together. Blank bounds mean Automatic: native probes look for a useful real window for the expression, preserving any endpoint you supply. This bounded search can miss narrow or distant features; supply bounds if it cannot find a useful view. Mathematical bounds such as -@pi and @pi are accepted.
    • 
            
  • Plot settings use radio buttons rather than dropdowns. Leave Plot type unselected to choose from the expression: a 3-D height surface when exactly one other non-constant variable is unset, otherwise a curve. Choose 2-D curve or 3-D surface to override this. The second variable is also automatic when no radio is selected. Reset clears an override without changing entered bounds. Bind any remaining parameters. Only the applicable camera or vertical-range controls are shown.
    • 
            
  • Surface dragging uses a coarser native preview for responsiveness, then restores full detail on release. Both retain precision checks; no spline smoothing is applied across discontinuities.
    • 
            
  • Over a 3-D plot, Ctrl-wheel changes elevation like a vertical drag; Alt-wheel changes azimuth like a horizontal drag. Wheel down increases the angle and wheel up decreases it in 5° steps. Sliders and readouts follow the camera; full-detail redraws coalesce rapid wheel movements. Shift takes precedence for zoom. Ctrl+Alt together does not rotate; wheel rotation is inactive during a drag.
    • 
            
  • Surfaces use blue-to-teal-to-gold height shading and three ticked axes, with positive-end arrows labelled by variable name (height is f). In the default view, the first variable runs along the rightward base axis, the second along the leftward base axis; height is the formula value. All plot controls are inside the Plot card, including when expanded. Use Update plot after changing ranges or plot type. Drag the Azimuth slider to rotate around the surface and Elevation to tilt it (5°–85°); Roll turns the view clockwise in the screen plane (0°–360°). Labels remain upright. Degree readouts update while sliding; releasing the slider redraws the surface. Keyboard and touch adjustment work too. Left-drag the 3-D plot to turn and tilt it: dragging down increases elevation; dragging up decreases it. Hold Shift when starting a left-drag to roll. Sliders, readouts and the surface update while dragging; only the latest camera position is queued while a redraw is in flight. Escape or losing browser focus cancels. Right-click is unchanged. The full 41×41 mesh leaves holes at missing real values. Surfaces fit all finite heights; 2-D Y controls do not apply.
    • 
            
  • Leave the 2-D vertical range radio buttons unselected for automatic scaling, which avoids letting extreme samples flatten the curve. Fit all includes all finite samples; Manual limits uses Minimum and Maximum. Reset clears the selection. Press Update plot to apply changes. Rounded decimal ticks and superscript scientific exponents keep axes readable.
    • 
            
  • Sampling normally uses a 53-bit mantissa, increasing precision for narrow ranges or failed higher-precision checks. It does not change either variable's worksheet value. Plot titles use the native TeX formula; recognised ellipsis series retain sigma notation.
    • 
            
  • The Plot card displays a native SVG generated in memory and delivered through Protobuf. The Expression card retains the formula; a plot has no separate numerical Value or Function programme.
    • 
            
  • Detected gaps are not joined. Adaptive sampling cannot guarantee finding every narrow feature or discontinuity; use a smaller range when necessary.
    • 
          

        

        

          
Running A Function Card

          
RUN executes the complete Function-card source at the selected precision. It is MARS source, not C or JavaScript, and is run by the native server.

          
    
            
  • Evaluate again after changing the editor or bindings, then press RUN on the newly generated card.
    • 
            
  • The card's Run output area shows the programme's output or a diagnostic with its source position. Running does not replace the main result cards.
    • 
            
  • Copying or running a shortened card uses its full source, not the abbreviated display. Replacing a result or changing mode clears the previous run output.
    • 
          

        

        

          
Solving Equations

          
Enter both sides of the equation. MARS tries symbolic solving first and uses numerical fallback where supported. There is no separate solve-variable selector: the variable and constant bindings describe the problem.

          
    
            
  • x^2 = 4 gives x = −2 and x = 2.
    • 
            
  • (x+1)^4 = 1 gives x = −2, x = 0 and x = −1 ± i. A paired ± row represents two roots.
    • 
            
  • abs(x-3) = 0 has only x = 3. Although abs(x-3) = 2 has mathematical roots 1 and 5, its numerical fallback may return only one. A starting value on the other side, such as { abs(x-3) = 2 | x=6 }, searches for the other root.
    • 
            
  • For numerical starting values and fixed parameters, use the binding boxes or an explicit envelope such as { M = E - e*sin(E) | E = 1.5; M = 1.5, e = 0.0167 }. Here E is the variable and M and e are constants.
    • 
            
  • A starting guess selects a numerical search; it does not guarantee every root. Try another guess when looking for another branch.
    • 
          

        

        

          
Reading Equation Solutions

          
    
            
  • Equation preserves the problem; Rendered TeX and Solutions show the returned roots. Long exact answers may define shared quantities such as A and B before using them in the roots.
    • 
            
  • A bar over a quantity denotes complex conjugation. Re and Im denote its real and imaginary parts; complex intermediate expressions can still give real roots.
    • 
            
  • No solutions means an empty solution set was established. Failure to find a numerical root or a timeout is not proof that no solution exists.
    • 
            
  • Domain conditions belong to the answer. Numerical searches, including searches for zeta zeros, are bounded and must not be read as a complete list of all possible roots.
    • 
          

        

        

          
Differential Equations

          
Type the equation itself, followed by any initial or boundary conditions separated by semicolons. The notation identifies the dependent and independent variables; without enough conditions, the solution retains arbitrary constants.

          
    
            
  • Dx(y) = x*y; y(0) = 1 is a first-order initial-value problem.
    • 
            
  • Dxx(y) = y; y(0) = 1; y'(0) = 1 is a second-order problem and uses prime notation in a condition.
    • 
            
  • Dxxx(y) + 3*Dxx(y) + 3*Dx(y) + y = x + sin(x) is a forced third-order constant-coefficient ODE.
    • 
            
  • y'' + 4y = exp(x), d²y/dx² + 4y = exp(x), and Dxx(y) + 4y = exp(x) are equivalent forms.
    • 
          

        

        

          
Using Matrix Mode

          
Enter the complete matrix expression in the main editor, choose the required matrix operation, then press Evaluate. A straightforward calculation can be completed as follows:

          
    
            
  1. Enter a matrix such as (1 2; 3 4). Spaces or commas separate columns; semicolons separate rows.
    2. 
            
  2. Leave Matrix operation set to Evaluate expression when the operation is already written in the editor, for example sin(1 2; 3 4) or (1 2; 3 4)^2. Otherwise choose a structural operation such as Inverse, Determinant, or Eigenvalues.
    3. 
            
  3. For Multiply by another matrix or Solve A X = B, enter the second matrix in the Right-hand side matrix box that appears.
    4. 
            
  4. Press Evaluate. If the matrix contains symbols, their binding boxes appear below the controls. Enter values only when a numerical result is wanted, or leave them blank for a symbolic result.
    5. 
            
  5. Use each binding's Variable/Constant button to change its role. This changes how MARS treats the symbol without replacing the expression you typed.
    6. 
            
  6. Use the derivative and integral buttons that appear for variable bindings to apply entrywise matrix calculus.
    7. 
          

          
The result side uses the same four-card arrangement as Expression mode. A structural operation can return a scalar: for example, trace(1 2; 3 4) gives 5 and det(1 2; 3 4) gives −2. Use as input returns a reusable result to the Matrix editor.

        

        

          
Matrix Functions

          
Write the complete matrix expression in the editor, then press Evaluate. These are genuine matrix functions calculated by MARSlib, not functions applied independently to each displayed entry.

          
    
            
  • sin(1 2; 4 5) calculates the sine of the complete 2x2 matrix. Spaces separate columns and semicolons separate rows.
    • 
            
  • inverse(a b; c d) and inv(a b; c d) calculate a symbolic inverse, while (a b; c d).(e f; g h) performs matrix multiplication. Matrix division is not defined. Matrix operations compose, so inv(a b; c d).(x; y) solves the corresponding 2x2 linear system.
    • 
            
  • det(A) and determinant(A) return a scalar determinant; trace(A) and tr(A) return a scalar trace.
    • 
            
  • transpose(A)/trans(A) transpose a matrix. hermitian(A), adjoint(A), ctranspose(A), conjtrans(A), and conjugate_transpose(A) calculate its conjugate transpose.
    • 
            
  • Dx(ax+b cx+d; y xy) differentiates every entry with respect to x. Repeated or mixed suffixes such as Dxx(A) and Dxy(A) request ordered higher or mixed derivatives.
    • 
            
  • @S(ax+b cx+d; y xy)dx returns an indefinite entrywise integral plus its constant matrix. @S^x(ax+b cx+d; y xy)dx returns the corresponding antiderivative without additive constants. Whitespace around the matrix and differential is optional.
    • 
            
  • Matrix functions require a square matrix. A rectangular matrix is rejected rather than having the scalar function applied entry by entry.
    • 
            
  • exp(0 1; -1 0) calculates the matrix exponential.
    • 
            
  • sqrt(4 0; 0 9) obtains (2, 0; 0, 3).
    • 
            
  • The native expression-function registry also supplies exponential, logarithmic, trigonometric, inverse-trigonometric, hyperbolic, error, gamma, normal-density, Lambert W, and exponential-integral matrix functions.
    • 
            
  • Exact symbolic matrices use an exact structured rule where one is available. Otherwise, supply numeric bindings before applying a general numeric matrix function.
    • 
            
  • Logarithms, inverse functions and special functions require a matrix whose spectrum lies in a supported domain; otherwise MARS Lab reports that the matrix function failed.
    • 
          

        

        

          
Matrix Operation Selector

          
Direct notation composes naturally, while the selector provides convenient access to structural operations.

          
    
            
  • Evaluate expression, Inverse, Eigenvalues, Eigendecompose, Characteristic polynomial, Determinant, Trace, Rank, and Simplify symbolic matrix use the main editor.
    • 
            
  • Multiply by another matrix and Solve A X = B reveal a right-hand matrix editor.
    • 
            
  • The selected operation, right-hand operand, and Matrix editor are retained between sessions. Back and Forward navigate Matrix workspace history.
    • 
          

        

        

          
Matrix Notation And Aliases

          
MARSlib parses the complete expression. The browser passes your text through unchanged and does not recognise function names itself.

          
    
            
  • Use +/- for same-sized matrices, . for ordered matrix multiplication, and ^ for integer, fractional, or symbolic powers. Parenthesised composite bases such as ((1 2; 3 4) - lambdaI)^x are accepted.
    • 
            
  • lambdaI, lambda.I, and lambda*I mean λ times the identity when the required order is clear.
    • 
            
  • A^dagger, A^H, A^*, A^†, and A† are postfix forms of the Hermitian adjoint.
    • 
            
  • |A|, ||A||, and ‖A‖ are determinant forms. Both opening and closing bars are required.
    • 
            
  • Matrix division is deliberately absent: A/B would not say on which side inv(B) should multiply.
    • 
            
  • lambda, @lambda, and λ are the same Greek symbol and render as λ.
    • 
          

        

        

          
Matrix Calculus And Values

          
    
            
  • The variable derivative and integral buttons apply entrywise and remain available while the corresponding variable is present.
    • 
            
  • Direct Dxx(A) and Dxy(A) notation supports ordered higher and mixed differentiation. Matrix integration uses the same @S(...)dx notation as scalar expressions.
    • 
            
  • An antiderivative is displayed as A(x) + C, where C is an independent constant matrix with entries C₁₁, C₁₂, C₂₁, and C₂₂ for a 2x2 result.
    • 
            
  • Rendered TeX, Expression, and Function preserve the symbolic answer. Value separately shows the numerical matrix once every required binding is supplied; it remains hidden while any entry is unresolved.
    • 
            
  • The Value card never abbreviates its numerical output. Long entries wrap within their matrix columns so the complete result remains visible.
    • 
            
  • Use as input copies the reusable result expression back into the Matrix editor.
    • 
          

        

        

          
Symbolic Matrix-power Calculus

          
For A = (1 2; 3 4), enter A^x as (1 2; 3 4)^x. Its eigenvalues are λ₊ = (5 + √33)/2 and λ₋ = (5 - √33)/2.

          
    
            
  • With spectral projectors P₊ = (A - λ₋I)/√33 and P₋ = (λ₊I - A)/√33, MARSlib represents the power exactly as A^x = λ₊^x P₊ + λ₋^x P₋.
    • 
            
  • x derivative gives ln(λ₊)λ₊^x P₊ + ln(λ₋)λ₋^x P₋.
    • 
            
  • x integral gives λ₊^x P₊/ln(λ₊) + λ₋^x P₋/ln(λ₋) + C, with an independent constant matrix C.
    • 
            
  • The result cards expand this compact spectral description into the exact 2x2 matrix containing √33.
    • 
            
  • The same spectral calculus applies to supported diagonalisable constant square matrices of any order. An eigenvalue-one projector differentiates to zero and integrates to a linear term.
    • 
            
  • Negative eigenvalues can introduce complex principal logarithms in powers and their derivatives. A real input matrix does not guarantee a real result for every exponent.
    • 
          

        

        

          
Bare D And Operator Polynomials

          
D is a differential operator. When it acts on x, MARS differentiates with respect to t; when it acts on any other dependent variable, MARS differentiates with respect to x.

          
    
            
  • D(y) = y means Dx(y) = y, while D(x) = x means Dt(x) = x.
    • 
            
  • D^2(z) + z = 0 means Dxx(z) + z = 0.
    • 
            
  • (D^2 - @omega^2)^2(x) = 0 expands the squared operator, treats omega as a constant, and solves for x(t).
    • 
            
  • (D^2 + @omega^2)^3x = 0 is also accepted. Literal positive integer powers up to 64 are expanded; solutions show every term for powers below 4 and use compact finite sums from power 4 onwards.
    • 
            
  • (Dx^2 + 4Dx + 20)^2(y) = 0 explicitly selects x as the differentiation variable.
    • 
          

        

        

          
Greek Symbols And Differential Forms

          
Prefix a Greek name with @ to enter its symbol unambiguously. Common plain Greek names are also recognised. Differential forms may be entered as coefficients followed by differentials.

          
    
            
  • @omega, @theta, and @phi display as ω, θ, and φ.
    • 
            
  • When it is a dependent variable, phi, @phi, and φ are identical and render as φ everywhere; for example, (D^2 + @omega^2)^4phi = 0.
    • 
            
  • (sin(theta)-2r cos^2(theta))dr + r cos(theta)(2r sin(theta)+1)dtheta = 0 is accepted as a differential form.
    • 
            
  • The same form may use @theta and d@theta; MARSlib performs the parsing and solving.
    • 
          

        

        

          
Partial Differential Equations And Results

          
    
            
  • Dx(u) + Dy(u) = 0 is a first-order PDE; u_x + u_y = 0 is equivalent shorthand.
    • 
            
  • phi_xx + phi_yy = 0 is the two-dimensional Laplace equation. Without boundary data, MARSlib returns its general harmonic family φ = F(x + i*y) + G(x - i*y).
    • 
            
  • phi_rr + 1/r phi_r + 1/r^2 phi_thetatheta = 0 is the polar form. Spaces between coefficients and derivative terms imply multiplication, Greek derivative suffixes are recognised, and MARSlib returns φ = F(r*exp(i*θ)) + G(r*exp(-i*θ)).
    • 
            
  • Use the explicit form { Dx(y) + a*y = x | x = ?; a = 2; y(0) = 1 } when you need to declare variables, constants, and conditions separately.
    • 
            
  • Solution displays the mathematical answer, Differential Equation the normalised problem, Solver the selected rule and any available working, and Solutions the returned solution text.
    • 
            
  • Arbitrary constants and arbitrary functions describe a family, not missing numerical values. Conditions restrict that family where the selected solver supports them; an unsupported problem is not proof that no solution exists.
    • 
          

        

        

          
Datetime Workflow

          
Use the calendar controls for the main date, date range, observance year, and location.

          
    
            
  • Date drives weekday, moon phase, estimated and almanac-backed actual sunrise/sunset, solar declination, inclination, and maximum altitude.
    • 
            
  • Start date and End date drive the days-between result.
    • 
            
  • Julian Day Number provides another way to select the civil date. Calendar year selects the observance year; Date supplies the current-date conversions.
    • 
            
  • Calendar groups Christian, Chinese, Hindu, Buddhist, Muslim, Jewish, Cherokee, Mayan, Aztec and Ethiopian dates and observances. Expand a section to see its entries.
    • 
            
  • Holiday country or jurisdiction supplies local holidays, the town list and local clock rules from the configured jurisdiction database. Selecting a town fills observer coordinates and altitude.
    • 
            
  • GMT offset should include daylight saving. Leave it blank to use the selected jurisdiction's local offset for the selected date.
    • 
            
  • Ramadan, Eid al-Fitr, and Muslim New Year use the civil Islamic calendar; Hindu and Buddhist observances are estimated from India-window lunar events, so observed dates can differ locally.
    • 
            
  • MARS supplies no shared weather account or key. Optional weather loads separately after the calendar results, using your configured WeatherAPI account. Its absence does not mean the calendar calculation failed.
    • 
            
  • When enabled, the local server sends that key, the selected date, and the observer coordinates to WeatherAPI.com over HTTPS. The key is not sent to the browser, and MARS does not retain the returned weather response.
    • 
            
  • Weather is informational and must not be the sole basis for safety-critical decisions. See the provider's privacy policy and terms.
    • 
          

        

        

          
Almanac Workflow

          
Use Almanac mode when you want celestial navigation style positions for a precise moment and observer.

          
    
            
  • Date and GMT time define the instant used by the ephemeris. The body table is calculated for that GMT instant.
    • 
            
  • Zone is used to present local event times, such as eclipse contacts. It does not change the GMT instant entered above.
    • 
            
  • Jurisdiction and Town/location fill in latitude, longitude, altitude, and local time rules where available.
    • 
            
  • You can type latitude, longitude, and altitude directly if the exact observing point is not in the town list.
    • 
            
  • The All/Visible toggle controls the body table only;
              events are still searched for the selected observer from the chosen GMT moment through one year ahead.
    • 
          

        

        

          
Reading The Body Table

          
    
            
  • Declination, RA, and GHA are apparent body coordinates for the selected GMT moment.
    • 
            
  • Altitude and Azimuth are observer-relative horizon coordinates for the selected latitude, longitude, and altitude.
    • 
            
  • s.d. is the apparent semi-diameter in arcminutes where the body has a visible disc.
    • 
            
  • Vmag. is visual magnitude. Lower numbers are brighter; negative values are very bright.
    • 
            
  • Visible means the body is above the usable local horizon and passes the daylight/eclipse visibility checks.
    • 
          

        

        

          
Eclipses And Transits

          
    
            
  • The event table starts at the selected GMT moment and covers one year ahead.
              An event already in progress remains listed until its final contact.
    • 
            
  • Date gives the local civil date of greatest eclipse or transit, so the row remains meaningful even if nearest totality cannot be found.
    • 
            
  • First, Greatest, and Fourth are local civil progress times. Use GMT when comparing against the body table.
    • 
            
  • Mag. is eclipse magnitude; Obsc. is obscuration or totality percentage.
    • 
            
  • Nearest totality lists the nearest town or location where totality can be observed when the selected observer sees only a partial eclipse.
    • 
            
  • Use the Use button on a nearest-totality result to jump the almanac to that town and moment.
    • 
            
  • Wide tables scroll within the worksheet; use Expand for more space. Contact tooltips and copied worksheet text retain the full dates and GMT offsets, even when a cell shows only a compact time.
    • 
            
  • The packaged ephemeris covers 1550–2649 GMT. Read the worksheet's coverage and accuracy notices; increasing mathematical precision cannot extend the ephemeris or make an event prediction a safety guarantee.
    • 
          

        

        

          
Integrator Workflow

          
The integrator editor is split into two parts: the expression at the top is the integrand, and the rows underneath describe the nested integrals.

          
    
            
  • A Bound row means "integrate with respect to this variable".
    • 
            
  • A Free row means "keep this symbol as a parameter".
    • 
            
  • Do not add rows for variables that are not in the integrand. A row named y means "integrate with respect to y", not "reserve a possible future variable".
    • 
            
  • Row order matters. The first row is the outermost integral shown on screen, and later rows sit further inside.
    • 
            
  • Use + and - on each row to insert or remove nested integrals without retyping everything.
    • 
          

        

        

          
Rows That Count

          
The lab sends only active rows to the integrator.

          
    
            
  • A row with both bounds filled is active, such as x = 0 .. 1.
    • 
            
  • A row with only an upper bound is active, such as t = x, and gives an upper-limit integral.
    • 
            
  • A blank Bound row is active only when its variable appears in the integrand, or when it is the only bound row.
    • 
            
  • A Free row is active only when its symbol appears in the integrand.
    • 
            
  • Spare blank rows that do not match the integrand are ignored and pruned after evaluation.
    • 
          

        

        

          
Common Recipes

          
    
            
  • Antiderivative: integrand sin(x), row x, both bounds blank.
    • 
            
  • Upper-limit form: integrand sin(t), row t, lower blank, upper x.
    • 
            
  • Definite integral: integrand x^2, row x, lower 0, upper 1.
    • 
            
  • Parameterised integral: integrand exp(-a*x^2), row a as Free, row x with bounds. Supply a parameter value when numerical evaluation requires it.
    • 
            
  • Nested integral: add one bound row per variable, for example x = 0 .. 1, y = 0 .. 1, z = 0 .. 1.
    • 
          

        

        

          
Reading Results

          
    
            
  • Rendered TeX shows the integral exactly as the lab interpreted it.
    • 
            
  • Exact result explains the path taken, for example symbolic reduction, convergence, or a work-budget cap.
    • 
            
  • Integral shows the numeric value and the reported integration error estimate.
    • 
            
  • work used tells you how much of the numeric budget the solver spent. A value of 1 often means a fast closed-form path or a very simple special case.
    • 
            
  • The Work budget ceiling limits numerical effort, not a fixed number of equally spaced samples. A higher ceiling can help a difficult integral but does not guarantee convergence.
    • 
            
  • The calculation also has a separate time limit, adjusted for precision and work ceiling and capped at two minutes. A timeout is not a value or a convergence result.
    • 
            
  • For a definite integral, fill both bounds. A lower bound without an upper bound is incomplete; blank lower and filled upper request the upper-limit form, not integration from zero.
    • 
          

        

        

          
Expression Shape

          
Type the expression body in the editor. Variable and constant bindings appear as editable boxes underneath.

          
    
            
  • x/pi becomes { x/π | x = ? }, but the editor keeps showing x/pi.
    • 
            
  • Set x to pi/2 in the binding box instead of writing the binding into the editor.
    • 
            
  • Raw expr binding syntax still works when you paste it, but the lab keeps the large editor focused on the expression body.
    • 
          

        

        

          
Bindings

          
Use each binding's Variable/Constant role control rather than relying on its colour. A variable can have a value; a constant can be unset.

          
    
            
  • A blank binding or x = ? is unset. It is not zero. Variable bindings provide derivative and integral buttons in Expression and Matrix modes where the operation is supported.
    • 
            
  • In an explicit envelope, variables follow | and constants follow ;: { x+a | x=2; a=3 } has variable x, constant a and value 5.
    • 
            
  • Binding values can use arithmetic: 3/2*pi, (pi^2)/2, 3/2+pi/7+3*i/5.
    • 
          

        

        

          
Transforms And Sums

          
    
            
  • Forward and inverse Laplace transforms use Laplace(f,t,s) and InverseLaplace(F,s,t). For example, Laplace(exp(-t),t,s) gives 1/(s+1) with Re(s) > −1.
    • 
            
  • Fourier transforms use Fourier(f,x,k) and InverseFourier(F,k,x). Keep the displayed domain and distribution qualifications, such as principal value, when copying a result.
    • 
            
  • sum(k,1,4,k) gives 10. Symbolic or infinite sums can retain a sigma and convergence conditions rather than a decimal value.
    • 
            
  • Unknown transforms or integrals may remain formal mathematical expressions when no supported closed form is available. This is different from obtaining a numerical value.
    • 
          

        

        

          
Roots And Complex Numbers

          
    
            
  • sqrt(z), cubrt(z) and root(z,n) select a single principal root. In scalar Expression calculations, an explicit fractional power can retain a family of roots instead; do not assume it means the same thing as a named principal-root function.
    • 
            
  • Plain mathematical output uses root indices, for example ³√x; compound radicands retain parentheses to avoid ambiguity.
    • 
            
  • Re(z) and Im(z) select real and imaginary parts. TeX uses their special typeface and places a bar over conjugated quantities instead of spelling conj.
    • 
            
  • For a branched Expression result, the numerical card is labelled Values and can contain several values. Equation solutions have their own root-list conventions.
    • 
          

        

        

          
Symbolic Derivatives

          
Derivative operators can be written directly inside an expression. MARS evaluates the derivative symbolically, so the differentiation variables can remain blank.

          
    
            
  • Dx(f(x)) differentiates f(x) once with respect to x.
    • 
            
  • Dxx(f(x)) and Dxxxxx(f(x)) take the second and fifth derivatives with respect to x.
    • 
            
  • Dxy(f(x,y)) takes a mixed derivative, first with respect to x and then y.
    • 
            
  • D[x^5](f(x)) is the compact form for a fifth derivative. Mixed compact orders such as D[x^2y^3](f(x,y)) are also accepted.
    • 
            
  • The x derivative button differentiates the whole current expression. Direct D... syntax is useful when the derivative is only one part of a larger expression.
    • 
          

        

        

          
When Evaluate Is Available

          
    
            
  • A valid expression such as sin(x) can be evaluated with x blank to obtain symbolic result cards. Supply a value for x when you want a numerical Value too.
    • 
            
  • A symbolic derivative such as Dx(sin(x)) can be evaluated with x blank because the result is another expression.
    • 
            
  • An unevaluated integral such as @S^x exp(u)du can likewise be evaluated with its bindings blank.
    • 
            
  • Constants may remain blank when you want them preserved symbolically in the result.
    • 
            
  • If simplification proves a numerical value independent of an unset binding, that value can still be shown. Missing bindings and a genuine calculation error are different states.
    • 
            
  • The binding boxes and Evaluate state come from the parsed MARS expression, including while you edit or remove symbols.
    • 
          

        

        

          
Goal Seek

          
Goal seek changes variable bindings so the expression value reaches the value in the Target field.

          
    
            
  • Variable bindings are adjustable even when they contain starting values. Change a binding to Constant if goal seek must keep it fixed.
    • 
            
  • Constants are not changed by goal seek.
    • 
            
  • With one variable, goal seek searches for a value reaching the target; it is not a promise to find every crossing.
    • 
            
  • If there are several variables, goal seek moves them together by the smallest local step it can find.
    • 
            
  • Current variable binding values become the starting point automatically.
    • 
            
  • Use the binding boxes in the main editor to seed a particular crossing or branch, for example target 27 with expression { x^x | x = 3 }.
    • 
            
  • For several variables, set whichever variable bindings you want to seed. Blank or unknown bindings still fall back to the solver's defaults.
    • 
            
  • Read the reported residual and diagnostic. A numerical search can fail or settle on a different branch; more precision is not a substitute for an appropriate starting guess.
    • 
          

        

        

          
Constants And Functions

          
    
            
  • Built-in constants include pi/π, e, i, phi/φ, and gamma/γ.
    • 
            
  • ln(x) is natural log; log(x), lg(x), and log10(x) are base-10 log.
    • 
            
  • Versine/haversine family names include versin, coversin, haversin, hacoversin, and their arc.../arch... inverses.
    • 
            
  • W(x) and productlog(x) use the branch-choosing Lambert W helper. Specify W0(x) for the principal branch or W-1(x) for the minus-one branch.
    • 
            
  • Standard gamma notation is supported in display: gamma(x) shows as Γ(x), and polygamma shows as ψ⁽ⁿ⁾(x).
    • 
          

        

        

          
Unary Functions

          
    
            
  • Elementary: abs(x), floor(x), ceil(x), sqrt(x), exp(x), ln(x), log(x), lg(x), log10(x).
    • 
            
  • Complex conjugation: conj(z), conjugate(z), and postfix z^* are equivalent.
    • 
            
  • Absolute value: abs(z) and paired bars |z| are equivalent for every scalar type. For complex values they mean sqrt(z*z^*); a missing closing bar is rejected.
    • 
            
  • Trigonometric: sin(x), cos(x), tan(x), asin(x), acos(x), atan(x).
    • 
            
  • Versine/haversine: versin(x), vercos(x), coversin(x), covercos(x), haversin(x), havercos(x), hacoversin(x), hacovercos(x).
    • 
            
  • Versine/haversine inverses: arcversin(x), arcvercos(x), arccoversin(x), arccovercos(x), archaversin(x), archavercos(x), archacoversin(x), archacovercos(x).
    • 
            
  • Hyperbolic: sinh(x), cosh(x), tanh(x), asinh(x), acosh(x), atanh(x).
    • 
            
  • Gamma family: gamma(x), gammainv(x), lgamma(x), digamma(x), trigamma(x), polygamma(n, x).
    • 
            
  • Error functions: erf(x), erfc(x), erfinv(x), erfcinv(x).
    • 
            
  • Exponential integrals: Ei(x), E1(x). The logarithmic integral is Li(x); it is distinct from the polylogarithm polylog(n,x).
    • 
            
  • Zeta functions: zeta(s), its derivative zetap(s), and Hurwitz zeta(s,a). Special functions retain their domain and branch restrictions.
    • 
            
  • Order-dependent special functions include BesselJ(n,x), BesselY(n,x), struve_h(n,x) and struve_l(n,x).
    • 
          

        

        

          
Lambert W And Normal Functions

          
    
            
  • Principal Lambert W: W0(x), W_0(x), W₀(x), lambert_w0(x). Use these explicit names when the principal branch is required.
    • 
            
  • Minus-one Lambert W branch: W-1(x), W_-1(x), W₋₁(x), lambert_wm1(x).
    • 
            
  • Normal distribution: normal_pdf(x), normal_cdf(x), normal_logpdf(x).
    • 
          

        

        

          
Binary Functions

          
    
            
  • pow(x, y) is equivalent to x^y.
    • 
            
  • atan2(y, x), hypot(x, y).
    • 
            
  • beta(x, y), logbeta(x, y), binomial(n, k).
    • 
            
  • Incomplete gamma: gammainc_lower(s, x), gammainc_upper(s, x), gammainc_P(s, x), gammainc_Q(s, x).
    • 
            
  • Exact integer helpers: gcd(a, b), lcm(a, b), mod(a, b), modinv(a, b).
    • 
            
  • Bitwise helpers use function syntax: AND(a, b), OR(a, b), XOR(a, b), NOT(a), SHL(a, n), SHR(a, n).
    • 
          

        

        

          
Value-Only Helpers

          
    
            
  • Discrete functions evaluate normally but are not differentiable, so derivative buttons are hidden when they control the expression.
    • 
            
  • Available helpers include factorial(n), n!, fibonacci(n), partition(n), isqrt(n), is_prime(n), next_prime(n), and prev_prime(n).
    • 
            
  • factors(n) returns the original value and shows its factorisation as constant bindings, for example factors(360) becomes { a₀³·a₁²·a₂ |; a₀ = 2, a₁ = 3, a₂ = 5 }.
    • 
          

        

        

          
Distribution Functions

          
    
            
  • Normal distribution: normal_pdf(x), normal_cdf(x), normal_logpdf(x).
    • 
            
  • Beta distribution: beta_pdf(x, a, b), logbeta_pdf(x, a, b).
    •
